# ChatGPT로 하는 데이터 분석 — 100분 수업 설계안

## 0. 개요

| 항목 | 내용 |
|---|---|
| 대상 | 고등학교 1~2학년, 코딩 경험 없음 전제 |
| 시간 | 100분 (블록 2차시 연강) |
| 편성 | 2인 1조, 5~8개 조 |
| 도구 | ChatGPT (파일 업로드 후 분석·그래프 생성 기능) |
| 준비물 | 조당 노트북 1대 이상, 로그인된 계정, 교사가 배포한 데이터 파일(CSV), 활동지, 실물 프로젝터 |
| 산출물 | 조별 "한 장 분석 카드" (질문 1개 + 그래프 1개 + 해석 3문장 + 검증 기록) |

### 이 수업의 원칙

ChatGPT가 분석을 대신해주는 수업이 아니다. **학생이 질문하고, ChatGPT가 계산하고, 학생이 검증하고 해석하는** 역할 분담을 몸에 익히는 수업이다. 그래서 마지막 20분은 "AI가 틀린 곳 찾기"에 쓴다.

### 학습 목표

1. 가진 데이터로 답할 수 있는 질문과 없는 질문을 구분한다.
2. 파일 업로드 → 데이터 파악 → 분석 → 그래프 → 해석까지 한 사이클을 스스로 돌린다.
3. AI가 내놓은 결과에서 오류나 과장을 최소 1건 찾아내고, 데이터를 근거로 반박한다.

## 1. 타임테이블

| 시간 | 블록 | 형태 | 핵심 |
|---|---|---|---|
| 0–10 | 도입: 속는 그래프 | 전체 | "이 그래프 믿을 수 있나?" |
| 10–22 | 미니 강의: 분석 4단계 | 강의 | 질문 → 데이터 → 계산 → 해석 |
| 22–35 | 교사 라이브 시연 | 시연 | 업로드부터 그래프까지 전 과정 |
| 35–52 | 실습 1: 데이터 파악 + 질문 만들기 | 조별 | 질문 3개, 그중 1개 선택 |
| 52–78 | 실습 2: 분석 + 그래프 + 검증 | 조별 | 분석 카드 완성 |
| 78–92 | 조별 공유 + 상호 검증 | 전체 | 1분 발표 + 반박 질문 |
| 92–100 | 정리 | 전체 | 체크리스트 + 과제 |

버퍼는 실습 2에 몰아넣었다. 진도가 밀리면 실습 2의 "심화 질문"을 잘라내면 된다.

## 2. 블록별 상세

### 블록 A. 도입 — 속는 그래프 (0–10분)

**교사 준비물:** 같은 데이터로 만든 서로 다른 그래프 2장.
- 그래프 1: y축이 0에서 시작 — 변화가 완만해 보임
- 그래프 2: y축이 최솟값 근처에서 시작 — 같은 데이터가 급등처럼 보임

**진행**
1. 두 그래프를 나란히 띄우고 묻는다. "둘 중 어느 쪽이 거짓말인가?" (1분 개별 생각 → 3~4명 발언)
2. 같은 데이터라는 걸 공개한다. 여기서 나오는 반응이 이 수업의 동기다.
3. 정리 문장: **"데이터는 하나지만 해석은 여러 개다. 그래서 해석하는 사람이 필요하다."**
4. 오늘 역할 분담을 칠판에 적는다.

```
계산 = ChatGPT
질문 = 나
검증 = 나
결론 = 나
```

**주의:** 여기서 AI 이야기를 먼저 꺼내지 않는다. "AI가 대신해준다"는 기대를 깔고 시작하면 검증 단계가 형식적으로 흐른다.

---

### 블록 B. 미니 강의 — 분석 4단계 (10–22분)

슬라이드 4장이면 충분하다. 강의는 12분을 넘기지 않는다.

**1) 질문 (Question)**

좋은 질문의 조건 3가지를 예시와 함께 제시한다.

| 조건 | 나쁜 예 | 좋은 예 |
|---|---|---|
| 데이터 안에 답이 있는가 | "우리 학교 급식은 왜 맛없나?" | "월별 급식 잔반량이 가장 많은 달은 언제인가?" |
| 숫자로 답이 나오는가 | "지하철이 붐비나?" | "평일 오전 7~9시 승차 인원 상위 5개 역은?" |
| 비교 대상이 있는가 | "1반 성적이 높다" | "1반과 2반의 평균 점수 차이는?" |

**2) 데이터 (Data)** — 행은 무엇 하나를 뜻하는가? 열은 몇 개이며 각각 무엇인가? 빠진 값은 없는가?

**3) 계산 (Compute)** — 평균, 합계, 비율, 순위, 시간 흐름. 고등학생 수준에서는 이 다섯 가지로 대부분 답이 나온다. 상관계수는 다루되 "상관 ≠ 인과"를 반드시 붙인다.

**4) 해석 (Interpret)** — 숫자를 문장으로 바꾼다. 형식을 고정해 주면 학생이 훨씬 쉽게 쓴다.

> "___ 데이터를 보면 ___가 ___이다. 그 이유는 ___ 때문일 수 있다. 다만 이 데이터만으로는 ___는 알 수 없다."

마지막 "알 수 없다" 칸이 이 수업에서 제일 중요한 칸이다. 발표 때 이 칸이 비어 있으면 감점.

### 블록 C. 교사 라이브 시연 (22–35분)

학생용과 **다른 데이터**로 시연한다. 같은 데이터로 하면 학생이 그대로 따라 치고 끝난다.

시연용 추천: 서울시 시간대별 지하철 승하차 인원 (교사용) / 학생용은 별도 세트.

화면을 띄우고 아래 순서를 실제로 친다. 학생에게는 활동지에 프롬프트만 받아 적게 한다.

**시연 순서 (약 10분)**

```
[1단계 — 역할 지정]
너는 데이터 분석을 도와주는 선생님이야.
나는 고등학생이고 코딩은 모르니까, 코드는 실행만 하고 결과는 쉬운 말로 설명해줘.
내가 시키지 않은 결론은 먼저 말하지 마.

[2단계 — 데이터 파악]  ※ 파일 업로드 후
이 파일에 뭐가 들어 있는지 알려줘.
1) 행이 몇 개, 열이 몇 개인지
2) 각 열이 무슨 뜻인지 (내용을 보고 추측한 거면 추측이라고 표시해줘)
3) 빠진 값이 있는 열이 있는지
표로 정리해줘.

[3단계 — 질문 검증]
내 질문은 "___"야.
이 데이터로 답할 수 있어? 답할 수 없다면 뭐가 부족한지 말해줘.
답할 수 있다면 어떤 계산을 해야 하는지 순서만 먼저 알려줘.

[4단계 — 분석]
그 순서대로 계산해줘. 결과는 표로 보여주고,
숫자가 어디서 나온 건지 한 줄로 설명해줘.

[5단계 — 그래프]
이 결과를 그래프로 그려줘.
- 어떤 그래프가 맞는지 먼저 이유와 함께 말해줘
- 축 이름과 단위를 꼭 넣어줘
- 글자가 깨지면 축 라벨은 영어로 써줘

[6단계 — 검증]  ★ 가장 중요
방금 분석에서 네가 틀렸을 가능성이 있는 부분을 3개 짚어줘.
그리고 이 결과로 말할 수 없는 것도 알려줘.
```

**시연 중 반드시 보여줄 장면 3개**

1. 3단계에서 일부러 답할 수 없는 질문을 넣어 거절당하는 장면. ("이 데이터에는 성별 정보가 없습니다.")
2. 5단계에서 한글 폰트가 깨지는 장면과 영어 라벨로 우회하는 장면.
3. 6단계에서 AI 스스로 한계를 말하는 장면. → "이걸 안 물어보면 AI는 그냥 자신 있게 말한다."

### 블록 D. 실습 1 — 데이터 파악과 질문 만들기 (35–52분)

**35–38분** 데이터 배포와 조 편성. 파일은 미리 조별 폴더나 공유 링크에 올려둔다. 현장에서 다운로드받게 하면 5분이 그냥 날아간다.

**38–47분** 1~2단계 프롬프트를 실행하고, 활동지 상단을 채운다.

> 이 데이터의 행 1개는 ( ) 하나를 뜻한다.
> 열은 총 ( )개이고, 그중 우리가 쓸 열은 ( ), ( ) 이다.
> 이상한 점: ( )

**47–52분** 질문 3개를 쓰고, 3단계 프롬프트로 각각 검증받는다. 통과한 질문 중 1개를 골라 활동지에 크게 적는다.

**교사 순회 포인트**
- "우리 조 질문 뭐예요?"라고 물어보고 답이 막연하면 → "그 답은 숫자 하나로 나와? 아니면 문장으로 나와?"
- ChatGPT가 시키지도 않은 분석까지 다 해버린 조 → 역할 지정 프롬프트를 다시 넣게 한다.
- 질문이 3개 다 비슷한 조 → "시간에 따라 변하는 질문 1개, 두 집단을 비교하는 질문 1개를 섞어봐."

---

### 블록 E. 실습 2 — 분석·그래프·검증 (52–78분)

**52–65분** 4~5단계. 표와 그래프를 뽑는다. 그래프는 활동지에 붙이거나 파일명을 기록한다.

**65–72분** 6단계 검증. 여기서 조별로 **AI가 틀렸거나 과장한 지점 1개 이상**을 찾아 적게 한다. 못 찾으면 아래 힌트 카드를 준다.

> **검증 힌트 카드**
> - 평균만 보고 말하지 않았나? 최댓값·최솟값도 확인했나?
> - 데이터 개수가 너무 적은 항목을 1등이라고 부르지 않았나?
> - "때문에"라고 썼는데 실제로는 "같이 움직인다"일 뿐 아닌가?
> - 빠진 값을 어떻게 처리했는지 물어봤나?
> - 같은 질문을 새 대화창에서 다시 물으면 같은 답이 나오나?

마지막 항목은 특히 효과가 좋다. 새 창에서 숫자가 달라지는 조가 나오면 전체에 공유한다.

**72–78분** 분석 카드 완성. 해석 3문장은 반드시 **학생이 직접 쓴다.** ChatGPT에게 요약을 시키면 이 활동은 의미가 없어진다. 활동지에 "AI가 쓴 문장 붙여넣기 금지" 문구를 넣어둔다.

---

### 블록 F. 공유와 상호 검증 (78–92분)

**형식:** 조당 60초 발표 + 다른 조의 반박 질문 1개 (30초).

발표 형식을 고정한다.
1. 우리 질문은 ___입니다.
2. 이 그래프를 보면 ___입니다.
3. 하지만 이 데이터로는 ___는 알 수 없습니다.
4. AI가 ___라고 했는데, ___여서 틀렸습니다.

**반박 질문 룰:** 듣는 조는 발표를 들으며 질문 하나를 준비한다. "왜 그 그래프를 골랐나요?" "숫자가 몇 개 기준인가요?" "다른 이유일 수도 있지 않나요?" 세 유형을 미리 칠판에 적어두면 정적이 생기지 않는다.

교사는 좋은 반박에 즉시 이름을 붙여준다. "지금 그건 표본 크기 문제야." "그건 상관을 인과로 읽은 거야."

---

### 블록 G. 정리 (92–100분)

**1) 오늘 배운 것 한 문장씩 받기** (3~4명)

**2) 체크리스트 배포** — 다음에 혼자 할 때 쓰는 것

```
□ 내 질문은 이 데이터로 답할 수 있는가
□ 행과 열이 무슨 뜻인지 확인했는가
□ 빠진 값을 어떻게 처리했는지 물어봤는가
□ 그래프에 축 이름과 단위가 있는가
□ "이 결과로 말할 수 없는 것"을 물어봤는가
□ 결론 문장을 내가 직접 썼는가
```

**3) 마무리 문장**

> "AI는 계산을 대신해주지만 책임은 대신 못 진다. 발표한 사람은 너였다."

**4) 과제 (선택)** — 본인이 관심 있는 주제로 공공데이터 1개를 찾아 오늘과 같은 분석 카드 1장 만들기. 제출은 다음 차시.

## 3. 데이터셋 준비 가이드

### 조건
- **20~2,000행.** 너무 작으면 분석할 게 없고, 너무 크면 업로드와 대기 시간이 길어진다.
- **열 5~10개.** 그 이상이면 고등학생이 데이터 구조 파악에서 시간을 다 쓴다.
- **한글 열 이름 허용, 단 파일은 CSV(UTF-8) 또는 XLSX.** 한글이 깨지면 그 자체를 수업 소재로 써도 좋다.
- **결측치를 일부러 몇 개 남겨둔다.** 깨끗한 데이터는 검증 활동을 무력화한다.

### 추천 소스 (수업 전 반드시 미리 내려받아 배포)

| 소스 | 검색어 | 왜 좋은가 |
|---|---|---|
| 서울 열린데이터광장 | "지하철 시간대별 승하차" | 시간 흐름·순위 질문이 자연스럽게 나옴 |
| 공공데이터포털 | "전국 초중고 급식 현황", "편의점 현황" | 학생 생활과 가까움 |
| 기상자료개방포털 | "종관기상관측 일별 자료" | 기온·강수 조합으로 상관 이야기 가능 |
| 학교알리미 | 학교 공시자료 | 자기 학교 데이터라 몰입도가 높음 |
| 자체 설문 | 구글폼 5분 제작 | **가장 안전한 백업.** 응답 CSV를 바로 씀 |

자체 설문 문항 예시(직전 차시나 조례 시간에 받아둔다): 하루 스마트폰 사용 시간(분), 취침 시각, 기상 시각, 통학 수단, 통학 시간(분), 주간 운동 횟수. 이 6개만으로도 "통학 시간이 긴 학생은 수면 시간이 짧은가?" 같은 질문이 나온다.

> **개인정보 주의:** 학생 설문을 쓸 때는 이름·학번·연락처를 받지 않는다. 반 정보도 조가 특정될 만큼 작으면 빼는 편이 낫다. 업로드 전에 교사가 열 목록을 한 번 더 확인한다.

## 4. 프롬프트 카드 (학생 배포용, 잘라서 사용)

```
────────────────────────────────
① 시작할 때
너는 데이터 분석을 도와주는 선생님이야. 나는 고등학생이고
코딩은 몰라. 결과는 쉬운 말로 설명하고, 내가 안 시킨 결론은
먼저 말하지 마.
────────────────────────────────
② 파일 올린 직후
이 파일에 뭐가 들어 있는지 표로 정리해줘.
행 개수, 열 개수, 각 열의 뜻, 빠진 값이 있는 열.
추측한 부분은 추측이라고 표시해줘.
────────────────────────────────
```

## 5. 평가 루브릭

| 항목 | 상 (3점) | 중 (2점) | 하 (1점) |
|---|---|---|---|
| **질문** | 데이터로 답할 수 있고 비교 대상이 분명함 | 답할 수는 있으나 범위가 모호함 | 데이터에 없는 것을 물음 |
| **분석 수행** | 계산 과정을 설명할 수 있음 | 결과는 얻었으나 과정 설명이 막힘 | AI 출력을 그대로 옮김 |
| **그래프** | 종류 선택 이유를 대고 축·단위가 정확함 | 그래프는 맞으나 라벨 누락 | 데이터에 맞지 않는 그래프 |
| **해석** | 한계("알 수 없는 것")를 명시함 | 결론은 있으나 한계 언급 없음 | 데이터를 넘어선 단정 |
| **검증** | AI 오류·과장을 근거와 함께 지적 | 지적은 했으나 근거가 약함 | 검증 시도 없음 |

15점 만점. 12점 이상이면 목표 도달로 본다. **검증 항목이 1점이면 다른 항목이 만점이어도 "도달"로 치지 않는다** — 이 수업의 핵심이 거기 있기 때문이다.

## 6. 자주 터지는 상황과 대처

| 상황 | 대처 |
|---|---|
| 무료 계정 파일 업로드/분석 횟수 제한에 걸림 | 조당 계정 1개만 쓰게 하고, 미리 조장 계정을 정해둔다. 제한에 걸린 조는 교사 화면으로 대신 돌려주고 해석은 조가 한다 |
| 로그인이 안 되는 학생 | 실습 전 5분을 로그인 확인에만 쓴다. 그래도 안 되면 그 학생은 "검증 담당"으로 역할을 준다 |
| 그래프 한글이 네모(□)로 깨짐 | 정상 현상이라고 알려준다. "축 라벨은 영어로 써줘" 또는 "한글 폰트를 설치해서 적용해줘" |
| CSV 한글이 깨져서 열림 | UTF-8로 다시 저장해 배포. 수업 중이면 그대로 쓰되 "인코딩" 개념을 1분 설명 |
| AI가 시키지도 않은 결론을 쏟아냄 | ① 프롬프트를 다시 넣게 한다. 이게 프롬프트가 왜 필요한지 보여주는 최고의 사례다 |
| 같은 질문에 다른 숫자가 나옴 | 즉시 전체 공유. 재현 가능성 이야기로 연결 |
| 실습 2에서 30분째 그래프만 예쁘게 다듬는 조 | "그래프는 도구야. 결론 문장 먼저 써." 타이머로 5분 남았음을 알린다 |
| 한 조가 너무 빨리 끝남 | 심화 카드: "다른 조 결과를 반박할 근거를 이 데이터에서 찾아봐" |

## 7. 확장 (다음 차시가 있다면)

- **2차시:** 조별 주제를 직접 정하고 공공데이터를 스스로 찾아 분석 → 3분 발표
- **심화:** 같은 데이터로 정반대 결론을 내는 그래프 2장을 일부러 만들어보기 (도입 활동의 회수)
- **교과 연계:** 확률과 통계(표본·평균·상관), 정보(데이터 표현·문제 해결), 사회(자료 해석), 과학 탐구 보고서 작성
- **평가 연계:** 분석 카드를 수행평가 산출물로 쓰되, "AI에게 시킨 프롬프트 전문"을 함께 제출하게 한다. 과정이 보이면 표절 판단이 쉬워진다
